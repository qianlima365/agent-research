# Ultra Plan 适用场景与成本分析

## 适用场景

| 场景 | 价值 |
|------|------|
| **架构设计** | 多方案对比，避免陷入单一思路 |
| **代码重构** | 不同重构策略评估 |
| **技术选型** | 多维度打分，量化决策依据 |
| **算法设计** | 多种实现方案的性能对比 |

## 不适用场景

- 简单任务（单一 Agent 即可胜任）
- 时间敏感任务（Ultra Plan 需要等待三个 Explorer 完成）
- token 预算有限的场景（成本约 4 倍）

---

## 成本对比

| 维度 | 单一 Agent | Ultra Plan（3E + 1C） |
|------|-----------|----------------------|
| **方案多样性** | 低（一种思路） | 高（三种策略） |
| **决策质量** | 依赖单次推理 | 多方案对比 + 独立评审 |
| **Token 成本** | 低 | 高（约 4 倍） |
| **耗时** | 短 | 较长（并行但仍需等待） |
| **适用场景** | 简单任务 | 复杂决策、高 stakes 场景 |

---

## 决策流程

```
任务复杂度评估
    ↓
简单 → 单一 Agent
中等 → 单一 Agent + 自我反思
复杂 → Ultra Plan（3 Explorer + 1 Critic）
```
